## 📅 6-Month Mathematics Study Plan

### Month 1: Number Theory Foundations
*The bedrock of all cryptography*

#### Week 1-2: Modular Arithmetic Refresher
**Day 1-3: Basic Operations**
```
Refresh these concepts:
- a ≡ b (mod n) means n divides (a-b)
- Addition: (a + b) mod n
- Multiplication: (a × b) mod n
- Powers: a^k mod n

Practice:
1. Compute 7^100 mod 13 (by hand using repeated squaring)
2. Find 17^(-1) mod 29 (modular inverse)
3. Solve 3x ≡ 7 (mod 11)
```

**Day 4-7: Chinese Remainder Theorem (CRT)**
```
Key insight for PQC: CRT enables parallel computation

Example: Kyber uses NTT with CRT
- Work modulo 3329 = 13×256 + 1
- Can split computations mod prime factors
- Recombine using CRT

Exercise: 
Given x ≡ 2 (mod 3), x ≡ 3 (mod 5), x ≡ 2 (mod 7)
Find x mod 105
```

#### Week 3-4: Finite Fields and Polynomial Arithmetic
**Day 1-4: Fields Zp (p prime)**
```
Crucial for PQC: All lattice schemes use finite fields

Concepts to master:
- Zp = {0, 1, ..., p-1} with +, × mod p
- Every non-zero element has multiplicative inverse
- Fermat's Little Theorem: a^(p-1) ≡ 1 (mod p)

Kyber example: Z3329
- 3329 is prime
- 17 is a primitive root (generates all non-zero elements)
- Used for Number Theoretic Transform
```

**Day 5-7: Polynomial Rings**
```
THE key structure for lattice crypto: Zq[x]/(x^n + 1)

Build intuition step by step:
1. Polynomials over Zq: a₀ + a₁x + ... + aₙ₋₁x^(n-1)
2. Addition: add coefficients mod q
3. Multiplication: like normal, but reduce by x^n + 1

Example in Z7[x]/(x^4 + 1):
(2 + 3x + x²) × (1 + 2x) = ?
= 2 + 4x + 3x² + 6x² + 2x³
= 2 + 4x + 9x² + 2x³
= 2 + 4x + 2x² + 2x³  (mod 7)
Now reduce by x^4 + 1: x^4 = -1
So our answer is: 2 + 4x + 2x² + 2x³
```

**Week 1-2 Practice Problems:**
1. Prove that x^n - 1 factors into cyclotomic polynomials
2. Why does Kyber use x^256 + 1? (Hint: it's irreducible)
3. Implement polynomial multiplication in Z3329[x]/(x^256 + 1)

### Month 2: Linear Algebra for Lattices
*Different focus than typical linear algebra*

#### Week 1-2: Vector Spaces and Matrices over Finite Fields
**Forget:** Eigenvalues, determinants over R
**Focus on:** Operations over Zq

```
Key concepts:
- Vectors in Zq^n (not R^n)
- Matrix multiplication mod q
- No inverses for most matrices (det = 0 mod q)

Example: Matrix-vector multiplication in Kyber
A ∈ Zq^(k×k), s ∈ Zq^k
b = As + e (where e is small "error")

This is Module-LWE: Learning With Errors over modules
```

#### Week 3-4: Introduction to Lattices
**The Heart of Modern PQC**

```
Definition: A lattice L is all integer combinations of basis vectors
L = {a₁v₁ + a₂v₂ + ... + aₙvₙ : aᵢ ∈ Z}

Example basis:
B = [4  1]
    [0  3]

Points in lattice: (4,0), (8,0), (4,3), (5,3), ...

Key problems (hard!):
1. SVP: Find shortest non-zero vector
2. CVP: Find closest vector to target
```

**Lattice Intuition Building:**
```
Day 1-2: 2D lattice visualization
- Draw lattices from different bases
- Same lattice, different bases (key insight!)

Day 3-4: Gram-Schmidt orthogonalization
- Not for solving, but for understanding "quality" of basis
- Bad basis = security in crypto

Day 5-7: Gaussian distributions over lattices
- Sample "short" vectors
- This randomness hides secrets in LWE
```

### Month 3: Abstract Algebra Essentials
*Just enough for PQC understanding*

#### Week 1-2: Groups and Rings
```
Groups (just one operation):
- (Z, +) integers under addition
- (Zn*, ×) units of Zn under multiplication
- Cyclic groups: generated by one element

Rings (two operations):
- (Z, +, ×) integers
- Zq[x] polynomials mod q
- Zq[x]/(f(x)) quotient rings ← Critical for PQC!

Focus: Polynomial rings Zq[x]/(x^n + 1)
- Understand why x^n + 1 (not x^n - 1)
- Connection to cyclotomic polynomials
```

#### Week 3-4: Ideals and Lattices Connection
```
Key insight: Ideals in rings ↔ Lattices in geometry

Example: In Z[x]/(x^n + 1)
Ideal I = (2 + x) generates a lattice

This connects:
- Algebraic structure (ideal)
- Geometric structure (lattice)
- Computational hardness (SVP in ideal lattice)
```

---

### Month 4: Probability and Statistics for Crypto
*Different from general statistics course*

#### Week 1-2: Discrete Distributions
```
Distributions in PQC:
1. Uniform over Zq
2. Binomial (approximates Gaussian)
3. Discrete Gaussian over Z

Key concept: Statistical distance
Δ(X,Y) = (1/2)Σ|Pr[X=x] - Pr[Y=x]|

If Δ(X,Y) < 2^(-128), distributions are cryptographically indistinguishable
```

#### Week 3-4: Security Reductions
```
Pattern: If you can break crypto scheme, you can solve hard problem

Example reduction:
"Breaking Kyber ⟹ Solving Module-LWE ⟹ Solving worst-case lattice problems"

Types of reductions:
- Tight: Equal difficulty
- Loose: Easier to break scheme than solve problem
- Quantum: Accounting for quantum algorithms
```

---

### Month 5: Computational Complexity for PQC
*Understanding hardness assumptions*

#### Week 1-2: Complexity Classes
```
Essential classes:
- P: Polynomial time (easy)
- NP: Verifiable in polynomial time
- BQP: Quantum polynomial time

Key insight: Factoring ∈ BQP (Shor's algorithm)
But: Lattice problems believed ∉ BQP
```

#### Week 3-4: Lattice Problem Hierarchy
```
Problem reductions:
SVP → CVP → LWE → Ring-LWE → Module-LWE

Understanding parameters:
- n: lattice dimension (security parameter)
- q: modulus (affects efficiency)
- σ: noise width (security/correctness tradeoff)

Concrete example:
Kyber-512: n=256, k=2, q=3329, η=2
This gives ~128-bit classical security
```

---

### Month 6: PQC-Specific Mathematics
*Putting it all together*

#### Week 1-2: Number Theoretic Transform (NTT)
```
The "FFT for finite fields"

Requirements:
- q ≡ 1 (mod 2n) so 2n-th roots exist
- ω^n ≡ -1 (mod q) for negacyclic convolution

Example: q=3329, n=256, ω=17
Check: 17^256 ≡ -1 (mod 3329) ✓

Why it matters:
- O(n²) polynomial multiplication → O(n log n)
- Enables practical lattice crypto
```

#### Week 3-4: Error Distributions and Correctness
```
The "Learning With Errors" part:
- Add small errors to linear equations
- Makes average-case as hard as worst-case

Correctness requirement:
||error||∞ < q/4 (roughly)

Balancing act:
- Larger errors = more security
- Smaller errors = better correctness
- Sweet spot: η = 2 or 3 for Kyber
```

## 🚨 Common Pitfalls to Avoid

1. **Don't skip modular arithmetic** - It's in every line of PQC code
2. **Don't over-focus on continuous math** - PQC is discrete
3. **Don't memorize without understanding** - Build intuition
4. **Don't ignore complexity theory** - It justifies parameters
5. **Don't rush to implementation** - Math first, code second
